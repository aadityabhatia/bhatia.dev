  • Saved as .py

Running Locally

How?

winget install astral-sh.uv # on Windows
dnf install uv # on Fedora Linux
brew install uv # on MacOS or Linux with Homebrew

uvx marimo edit new.py

uv tool install marimo

Why?

  • WASM Native Runtime
    • More packages!
  • Memory, hardware access
  • Network Access
  • Real AI integration!

Which AI model to use?

Ideal World

  • Tokens are free and unlimited
  • Frontier models everywhere
    • A hammer is all you need!
  • Companies care about your privacy

Reality

  • Students must experiment and discern
  • Bring your own tokens
  • “Claude” is not a model
    • Understand what works when!
